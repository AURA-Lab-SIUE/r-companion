# Open your course workspace

R finds a file by its name only when the file is in the folder VS Code has open. So every course file lives in one folder, and you open that folder in VS Code.

**MC 427:** your folder is your copy of the course folder, named `MC427`. You make the copy on GitHub once (GitHub guide, Part 6), then open it in VS Code (Part 7). In a codespace it is already open.

**MC 451 and MC 501:** your folder is your copy of the **v2v-workspace** template. The hub's Getting Started page, Steps 1 and 4, shows how to make the copy and clone it.

**AURA: Open my course workspace** offers each step: open a folder already on this computer, clone your copy from GitHub, make your copy first, or read the guide.

## Made your copy before this extension existed?

Copies made from a template earlier in the term do not get files added to the template later. **AURA: Add the course's Copilot instructions to this folder** adds two small files to the open folder: `.github/copilot-instructions.md`, which tells GitHub Copilot Chat to write code the way this course does, and a line in `.vscode/extensions.json` that recommends this extension. It never replaces a file you already have. Commit the change in **Source Control** so it reaches your copy on GitHub.
