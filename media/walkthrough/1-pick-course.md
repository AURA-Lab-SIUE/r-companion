# Pick your course

The three courses use R a little differently, so the extension needs to know which one you are in.

| Course | What it checks |
|---|---|
| MC 427 Social Media Analytics | R 4.2 or newer, the **tidyverse** and **effectsize** packages, and Git |
| MC 451 Research Methods | R, the course package **v2v** from GitHub, the packages the hub's Install R page lists, Quarto, and Git |
| MC 501 Research Methods (graduate) | Everything MC 451 checks, plus **effectsize** as a recommended package |

You pick once. The extension remembers your answer. To change it later, open the Command Palette (**Ctrl+Shift+P**, or **Cmd+Shift+P** on a Mac) and run **AURA: Pick my course**.
